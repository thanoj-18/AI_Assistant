# AI Personal Assistant

A simple AI-powered personal assistant built with Flask and Groq API.

# Features
💬 Ask Anything — Get AI-powered answers to your questions.
📧 Email Summarizer — Paste an email and get a concise summary.
⚡ Fast AI responses using Groq.
🌐 Simple and clean web interface.
🔐 API key stored securely using environment variables.
# Tech Stack
Python
Flask
Groq API
OpenAI Python SDK
HTML
CSS
JavaScript
